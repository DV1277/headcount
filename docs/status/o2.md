# O2 · HUD foundation

Scope: first scaffold and contract phases only, per HEAD's narrowed task. This is the HUD shell and a concrete fixture-replay view; it does not implement U-04 through U-10.

Implemented in the owned paths:

- Parchment and ink tokens, IBM Plex / Pixelify Sans typography, and the responsive three-region HUD frame from PRD §10.
- Default `Hud` export and `ui/index.ts` barrel for App integration.
- Visible mode and connection badges, run title, current run status, team state, payroll, sequence/time, and recent event log.
- Read-only plan summary and plan task viewer when a plan exists.
- Empty-state choices open `golden-boba`, `failure-retry`, or `redirect`; replay controls expose play/pause, speed, seek, history return, and keyboard shortcuts.
- Preview state is labeled before a run starts, load errors are visible, and fixture payroll is clearly labeled as sample usage.
- HUD shortcuts handle replay play/pause, ±5 second seek, and replay restart; inputs and buttons keep their normal keyboard behavior.
- Fonts are bundled from the existing `@fontsource` dependencies, with no Google Fonts runtime request.
- No live run is started by the HUD. The store's live start action checks health and configured keys before creating a run.

Validation: `npm run typecheck` and `npm run build --workspace @hc/web` pass. Vite reports the existing combined JS chunk above its 500 kB advisory threshold. HEAD verified the final desktop and 1280 px views after Sol fixes: [HEAD.md](HEAD.md), [review-ui.md](review-ui.md). No API keys or paid calls are needed for this UI path.
